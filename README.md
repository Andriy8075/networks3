# ЛР3. Моніторинг мережевої інфраструктури

Перед запуском коду третьої лабораторної роботи код першої лабораторної роботи повинен бути запущений. Код першої лабораторної роботи можна знайти за посиланням. https://github.com/Andriy8075/networks1

## Запуск

Скопіюйте `.env.example` в `.env` і задайте паролі. Community SNMP для цього стенда обмежена мережею `172.31.0.0/24`.

```text
docker compose up -d --build
```

Сервіс `bootstrap` створює вузли, шаблони, веб-сценарій, тригери, користувача Grafana і дашборд. Пароль адміністратора Zabbix лишається заводським `zabbix`.

На хост опубліковано веб-інтерфейс Zabbix `8081` і Grafana `3000`. База Zabbix, сервер, агент і SNMP назовні не відкриті.
